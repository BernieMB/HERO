# H.E.R.O. — HERO_v2

Juego de rescate y exploración en HTML, CSS y JavaScript, inspirado en el clásico **H.E.R.O. de Commodore 64**.

- **[Leer el manual en HTML](README.html)**: presentación, controles, mecánicas y detalles técnicos. Descarga el repositorio y abre `README.html` en el navegador para verlo con su diseño completo.
- **[Abrir el juego](hero.html)**: abre `hero.html` en un navegador moderno y pulsa **Espacio** o **Enter** para empezar.

No requiere instalación, dependencias ni servidor. Tanto el juego como el manual funcionan sin conexión.
